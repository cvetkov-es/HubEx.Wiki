#### Массовые действия для списка заявок

В этом разделе вы узнаете:

* [Как назначить исполнителей на несколько Заявок](https://wiki.hubex.ru/docs/FAQ/RU/user/GroupActionsForTickets.html#performer);
* [Как массово изменить стадию Заявок](https://wiki.hubex.ru/docs/FAQ/RU/user/GroupActionsForTickets.html#stage);
* [Как массово вернуть заявки в работу](https://wiki.hubex.ru/docs/FAQ/RU/user/GroupActionsForTickets.html#returntowork);
* [Как удалить несколько Заявок](https://wiki.hubex.ru/docs/FAQ/RU/user/GroupActionsForTickets.html#deleting).

С помощью массовых действий над списком заявок можно быстро добавить/изменить определенные параметры сразу в
нескольких **Заявках**:

* заполнить/заменить **Исполнителя**;
* изменить **Стадию** сразу у нескольких **Заявок**;
* вернуть в работу несколько закрытых **Заявок**;
* удалить **Заявки**.

##### Как назначить исполнителей на несколько Заявок

Откройте список всех **Заявок** в меню **Заявки - Все заявки**.

Обратите внимание! Массовые действия доступны для карточного и табличного представления списка. Подробно о форматах представления списка читайте в статье: [Список заявок, поиск заявок с помощью фильтров](Filters.md).

Чтобы назначить исполнителей на несколько **Заявок**, необходимо:

1. Выберите нужные **Заявки**: отфильтруйте список по нужным критериям (например, по **Заказчику**, **Объекту** или **Виду работ**) или отметьте **Заявки** вручную флажками прямо в карточном или табличном представлении списка.

   ![](https://wiki.hubex.ru/attachments/images/FAQ/USER/GroupActionsForTickets/Tickets.jpg)

   Использование фильтров целесообразно при большом количестве **Заявок** в списке для того, чтобы минимизировать
   ошибку выбора их вручную. Данный шаг не является обязательным. Подробнее о работе с фильтрами читайте в статье: [Список заявок, поиск заявок с помощью фильтров](Filters.md).
2. Теперь нужно включить режим массовых действий. Наведите курсором мышки слева от
   любой **Заявки** из отфильтрованного списка. Вы увидите, как появится окошко для установки флажка выбора.

   ![](https://wiki.hubex.ru/attachments/images/FAQ/USER/GroupActionsForTickets/SelectEmpty.jpg)

   Установите флажок. Сверху появится панель редактирования. Выбрать все **Заявки** на странице можно с помощью
   установки флажка в панели редактирования. Либо продолжить выбор **Заявок** с помощью установки флажков вручную

   ![](https://wiki.hubex.ru/attachments/images/FAQ/USER/GroupActionsForTickets/SelectedTick.jpg)
3. Нажмите кнопку **Редактировать**. Откроется форма для выбора параметров. Чтобы назначить исполнителей, нажмите кнопку
   **+ Изменить**.

   Обратите внимание! С помощью данного функционала можно назначать исполнителей как на **Заявки**, где исполнитель еще не был указан, так и на **Заявки**, где уже был выбран исполнитель(ли).

   ![](https://wiki.hubex.ru/attachments/images/FAQ/USER/GroupActionsForTickets/Edit.jpg)
4. Выберите специалистов, которых нужно назначить на **Заявки** и нажмите кнопку **Выбрать**.

   ![](https://wiki.hubex.ru/attachments/images/FAQ/USER/GroupActionsForTickets/ParamsSelect.jpg)
5. Нажмите кнопку **Применить**.

   ![](https://wiki.hubex.ru/attachments/images/FAQ/USER/GroupActionsForTickets/ParamsSelect2.jpg)

Назначенный исполнитель(ли) сразу отобразятся для выбранных **Заявок**.

![](https://wiki.hubex.ru/attachments/images/FAQ/USER/GroupActionsForTickets/Performer.jpg)

##### Как массово изменить стадию Заявок

Откройте список всех **Заявок** в меню **Заявки - Все заявки**.

Чтобы изменить стадию сразу у нескольких **Заявок** (до 500 за один раз), необходимо:

1. С помощью фильтров или вручную выберите нужные **Заявки** — так же, как при назначении исполнителя (см. выше).
2. Нажмите кнопку **Редактировать**, затем — кнопку **Изменить стадию**.
3. Выбранные **Заявки** автоматически группируются по **Типу заявки** и текущей стадии. Раскройте группу, чтобы увидеть номер, описание и дату создания входящих в неё заявок.

   ![](https://wiki.hubex.ru/attachments/images/FAQ/USER/GroupActionsForTickets/StageGroups.jpg)
4. Для каждой группы выберите новую стадию из списка доступных переходов. Если для группы переход недоступен, появится сообщение **«Изменение стадии этих заявок недоступно»** — такую группу можно пропустить, остальные заявки при этом сохранят выбранные стадии.

   ![](https://wiki.hubex.ru/attachments/images/FAQ/USER/GroupActionsForTickets/StageApply.jpg)
5. Нажмите кнопку **Сохранить**.

Изменение стадий выполняется в фоновом режиме; по завершении появится уведомление **«Массовый перевод заявок по стадиям завершён»**. Каждый перевод фиксируется на вкладке **История изменений** соответствующей заявки. Вам доступны для выбора только те стадии, на которые у вас есть права перехода.

##### Как массово вернуть заявки в работу

Откройте список всех **Заявок** в меню **Заявки - Все заявки**.

Чтобы вернуть в работу сразу несколько закрытых **Заявок**, необходимо:

1. Выберите нужные **Заявки** — так же, как при назначении исполнителя (см. выше). Функция доступна только для **Заявок** в стадии **«Закрыта»** и только пользователям с полномочием **«Изменение закрытых заявок»**.
2. Нажмите кнопку **Редактировать**, затем — кнопку **Вернуть в работу**.
3. Выбранные **Заявки** автоматически группируются по **Типу заявки** и текущей стадии. Раскройте группу, чтобы увидеть номер, описание и дату создания входящих в неё заявок.

   ![](https://wiki.hubex.ru/attachments/images/FAQ/USER/GroupActionsForTickets/ReturnToWorkGroups.jpg)
4. Для каждой группы выберите стадию, на которую нужно перевести **Заявки** (текущая стадия заявки недоступна для выбора).

   ![](https://wiki.hubex.ru/attachments/images/FAQ/USER/GroupActionsForTickets/ReturnToWorkApply.jpg)
5. Нажмите кнопку **Сохранить**.

Возврат в работу фиксируется на вкладке **История изменений** каждой заявки: смена признаков «Завершена» и «Закрыта» с «Да» на «Нет». Подробнее о возврате в работу одной заявки читайте в статье: [Возврат закрытой заявки в работу](https://wiki.hubex.ru/docs/FAQ/RU/user/ChangingStatus.html#returntowork).

![](https://wiki.hubex.ru/attachments/images/FAQ/USER/GroupActionsForTickets/TicketList.jpg)

Найти и просмотреть удаленные **Заявки** можно с помощью фильтров: выбрать в разделе **Видимость заявок** вариант **Только удаленные**.
