### 1. Что это и как устроено

«Печатные формы» — это инструмент внутри HubEx, который позволяет один раз нарисовать **шаблон** документа и затем печатать по нему документы для любой заявки. Данные (номер заявки, заказчик, адрес, выполненные работы, суммы и т.д.) подставляются в шаблон автоматически.

Инструмент состоит из двух частей:

| Часть | Кто пользуется | Где находится |
| --- | --- | --- |
| **Конструктор** | тот, кто создаёт и правит шаблоны | раздел «Печатные формы» в HubEx |
| **Готовая форма** | исполнители, диспетчеры, менеджеры | на карточке заявки, во вкладке/кнопке с названием формы |

Как это выглядит по шагам:

1. В конструкторе вы настраиваете шаблон и **публикуете** его.
2. Форма появляется на карточках заявок у тех ролей, которым вы её открыли.
3. Пользователь открывает заявку → форму → видит документ с уже подставленными данными → печатает его или скачивает в Word.

> **Важно.** Ручные правки, внесённые в готовую форму в заявке, **нигде не сохраняются** — они доступны только для печати, пока пользователь находится на странице печатной формы. При следующем открытии форма собирается заново из актуальных данных заявки.

#### Не хватает возможностей конструктора печатных форм?

Наш конструктор печатных форм позволяет быстро и удобно создавать печатные формы разной сложности без привлечения разработчиков.

Если вам необходима печатная форма с иной логикой, которую не покрывает конструктор, пожалуйста, обратитесь к вашему менеджеру в HubEx или через сайт [HubEx](https://hubex.ru/services/automate). Наша команда разработки сможет реализовать для вас кастомную печатную форму в рамках индивидуальных доработок.

### 2. Список форм

Открыв раздел «Печатные формы», вы попадаете в **список форм** вашей компании.

#### Что на экране

* **Заголовок «Печатные формы (N)»** — сколько всего форм создано.
* **Поиск по названию** — вводите часть названия, список сужается.
* **Вкладки** «Все», «Опубликованные», «Черновики» — в скобках количество форм (с учётом поиска).
* **Кнопка «Создать форму»**.
* **Таблица форм**:

| Колонка | Что означает |
| --- | --- |
| Название | название формы; клик по строке открывает конструктор |
| Описание | краткое пояснение (для себя и коллег) |
| Статус | «Черновик» или «Опубликована». Значок телефона рядом — у формы стоит галка «Мобильная» (значок есть и у черновика, хотя в приложение он попадёт только после публикации) |
| Активна | переключатель; есть **только у опубликованных** форм |
| Изменена | дата и время последнего сохранения |
| (без заголовка) | кнопки «Редактировать» (карандаш), «Дублировать», «Удалить» (корзина) |

* Внизу — переключение страниц и выбор «Форм на странице» (25 / 50 / 100).

#### Что можно сделать с формой

| Действие | Как | Результат |
| --- | --- | --- |
| Открыть на редактирование | клик по строке или карандаш | откроется конструктор |
| **Выключить / включить** форму | переключатель «Активна» | Выключенная форма пропадает с карточек заявок у всех (и из мобильного приложения), но **не удаляется** — включить её обратно можно в любой момент: здесь же или кнопкой «Включить» в конструкторе (см. 3.10) |
| **Дублировать** | кнопка «Дублировать» | появится новый **черновик** «Название (копия)» |
| **Удалить** | корзина → «Удалить» в окне подтверждения | форма исчезнет безвозвратно; отменить нельзя |

> **Про дублирование.** В копию переносится вся форма: название, описание, содержимое, ориентация листа, режим пустых значений, колонтитулы, признаки «Редактируемая» и «Мобильная». Копия — черновик: пользователи её не видят, пока вы её не опубликуете.

### 3. Создание формы: конструктор

Нажмите **«Создать форму»** (или откройте существующую). Откроется окно конструктора: сверху — шапка и настройки, ниже — панель инструментов, в центре — **лист A4**, справа — **панель переменных**.

#### 3.1 Шапка конструктора и настройки формы

**Верхний ряд**

| Элемент | Для чего |
| --- | --- |
| Стрелка «К списку форм» | вернуться в список. Подтверждения нет: несохранённые правки остаются только в копии в этом браузере (см. 3.9) |
| **Название формы** | как форма будет называться на заявке и в имени скачиваемого файла |
| **Описание** | заметка для коллег; видна в списке в конструкторе |
| **Мобильная** | если включить — форма будет доступна и в мобильном приложении HubEx (см. раздел 5). У выключенной формы галка заблокирована |
| Значок статуса | «Черновик», «Опубликована» или «Выключена» (опубликована, но выключена переключателем «Активна» в списке) |
| **Доступ по ролям** | выбор ролей, которые увидят форму (см. 3.10) |
| **Сохранить** | у черновика и у выключенной формы: сохраняет форму, пользователям ничего не меняется |
| **Опубликовать** / **Сохранить** / **Включить** | основная кнопка (см. 3.10): у черновика — «Опубликовать»; у опубликованной формы кнопка одна и называется «Сохранить» — она сохраняет и обновляет форму у пользователей; у выключенной — «Включить» |

![](https://wiki.hubex.ru/attachments/images/FAQ/USER/PrintingFormDesigner/IMAGE2.jpg)

**Второй ряд — настройки листа и поведения**

| Настройка | Варианты | Что делает |
| --- | --- | --- |
| **Ориентация листа** | Книжная / Альбомная | размер и поворот страницы при печати и в Word (A4) |
| **Пустые значения** | «Прочерк» / «Не отображать» | что показывать, если данных нет. «Прочерк» — печатается `_________`; «Не отображать» — место остаётся пустым |
| **Редактируемая** | галочка | разрешает пользователю **править текст готовой формы** на заявке перед печатью (без сохранения) |
| Подпись справа | «Не сохранено» (красным) / «Сохранён…» | состояние сохранения |

> **Подсказка про широкие таблицы.** Если в книжной ориентации вы вставили таблицу больше чем из 5 колонок, над листом появится жёлтая плашка «Широкая таблица может не поместиться по ширине листа» с кнопкой **«Сделать альбомной»**.

![](https://wiki.hubex.ru/attachments/images/FAQ/USER/PrintingFormDesigner/IMAGE3.jpg)

#### 3.2 Оформление текста

Панель инструментов над листом (слева направо):

| Группа | Возможности |
| --- | --- |
| Отмена | «Отменить», «Повторить» |
| Начертание | Жирный, Курсив, Подчёркнутый, Зачёркнутый, Надстрочный, Подстрочный, Цвет текста, «Очистить форматирование» |
| Шрифт | выбор шрифта; **размер** из списка или «Другой…» (свой размер, 6–120 пт), «Авто» — размер по умолчанию |
| Стиль абзаца | «Обычный текст», «Заголовок 1/2/3» |
| Абзац | по левому краю / по центру / по правому краю (повторный клик снимает выравнивание), маркированный и нумерованный списки, уменьшить/увеличить отступ, межстрочный интервал |
| Вставка | таблица (2×3 с заголовком), картинка, горизонтальная линия, **разрыв страницы**, «Исходный HTML», ссылка |

Полезное:

* **Картинка.** Выберите файл на компьютере — она вставится и сама уменьшится, если шире листа. Чтобы изменить размер, потяните за **серый квадратик в правом нижнем углу** картинки. Картинку можно ставить прямо в строку с текстом.
* **Ссылка.** Выделите текст → кнопка «Ссылка» → введите адрес. Если ничего не выделено, в документ вставится сам адрес. Повторное нажатие на ссылке — «Убрать ссылку».
* **Разрыв страницы.** Вставляет линию «разрыв страницы» — при печати и в Word всё, что ниже, начнётся с новой страницы. **Автоматических границ страниц в конструкторе нет**: длина данных (например, число выполненных работ) заранее неизвестна, поэтому место разрыва определяет только вы или сама печать.
* **Исходный HTML** (кнопка `</>`) — для опытных пользователей: показывает и позволяет править код всего шаблона. Например, можно вставить готовый HTML, подготовленный другим инструментом. Окно закрывается **только кнопками** («Применить»/«Отмена»), чтобы случайный клик не стёр вашу работу.

![](https://wiki.hubex.ru/attachments/images/FAQ/USER/PrintingFormDesigner/IMAGE4.jpg)

#### 3.3 Вставка данных заявки (переменные)

**Переменная** — это «окошко» в шаблоне, куда при печати подставится значение из заявки (например, «Номер заявки»). В шаблоне переменная выглядит как **цветная плашка** с названием. К ней можно применять обычное оформление (жирный, размер, цвет) — значение при печати унаследует его.

Вставить переменную можно тремя способами.

**Способ 1. Панель переменных (справа)**

1. Поставьте курсор в нужное место листа.
2. В панели найдите группу (например, «Дата выполнения») и нажмите на нужное поле.

![](https://wiki.hubex.ru/attachments/images/FAQ/USER/PrintingFormDesigner/IMAGE5.jpg)

В панели:

* **Поиск** ищет и по названию переменной, и по названию группы;
* кнопки **«Развернуть»/«Свернуть»** раскрывают или сворачивают все группы;
* число рядом с названием группы — сколько в ней пунктов.

**Способ 2. Быстрый поиск по `{{`**

Наберите в тексте `{{` (или `@`) и начинайте вводить название — появится список подсказок.

![](https://wiki.hubex.ru/attachments/images/FAQ/USER/PrintingFormDesigner/IMAGE6.jpg)

* Стрелки ↑↓ — выбор, **Enter** или **Tab** — вставить, **Esc** — закрыть.
* Если вы набрали название целиком в двойных фигурных скобках, например `{{Номер заявки}}`, и оно однозначно — скобки сами превратятся в плашку.
* Если название встречается у нескольких групп («ИНН» у заказчика, плательщика и получателя), уточните: `{{`Компания-заказчик | ИНН`}}`.
* Последний пункт списка всегда — **«ƒ Вычисляемое значение…»** (см. 3.7).

**Способ 3. Диалоги для таблиц и блоков** — см. 3.5 и 3.6.

**Какие данные доступны** (группы панели):

| Группа | Примеры полей |
| --- | --- |
| Заявка | номер, описание, статус, стадия, тип, адрес, заявитель, исполнитель, исполнители (список), даты создания/срока/выполнения/закрытия, стоимость (фактическая/оценочная), трудозатраты, оценка, договор и его статус |
| Объект обслуживания | название, серийный номер, гарантия до, адрес, тип, класс, ответственный, план объекта |
| Компания-заказчик / плательщик / получатель | название, ИНН, КПП, ОГРН, адреса, телефон, e-mail и т.д. |
| Банк заказчика / плательщика / получателя | банк, расчётный счёт, БИК, корр. счёт (основной счёт) |
| Договор | название и номер, описание, условия, срок действия |
| Выполненные работы | таблица работ, блок «Выполнение», итоговые суммы, вложения |
| Материалы выполненных работ | материал, количество, стоимость, сумма, склад, кто взял |
| Контакты заявки / заказчика / объекта | ФИО, телефон, e-mail, должность (таблицы) |
| Исполнитель / Инициатор / Составитель | ФИО, телефоны, e-mail; отдельно — трудоустройство (должность, компания, табельный номер) и дополнительные поля. «Составитель» — тот, кто печатает форму |
| Исполнители заявки | таблица всех исполнителей с телефонами и должностью |
| Чек-листы | блок чек-листов, вложения |
| Подпись | картинка подписи, ФИО и должность подписанта |
| QR-код объекта | QR-код маркировки объекта |
| История стадий / История статусов | таблицы изменений |
| Документ | дата и время формирования, вычисляемое значение |
| Доп. поля … | дополнительные поля заявки, объекта, компаний, работ (их названия ваши собственные) |

#### 3.4 Настройка переменной

Кликните по плашке переменной — рядом появится маленькое меню. Что в нём есть, зависит от типа данных. Если настраивать нечего, в меню только заголовок, корзина (удалить) и крестик (закрыть).

![](https://wiki.hubex.ru/attachments/images/FAQ/USER/PrintingFormDesigner/IMAGE7.jpg)

| Тип данных | Что можно настроить |
| --- | --- |
| **Число / деньги** | «Считать» — формула (см. 3.7); «Знаков» — число знаков после запятой |
| **Дата / дата и время** | «Дата»: `DD.MM.YYYY` или `D MMMM YYYY` (например, «5 мая 2026»); «Время» (только у даты с временем): «не показывать» или `HH:mm`. |
| **Трудозатраты** | «Единицы»: чч:мм:сс (по умолчанию), минуты, часы (чч:мм), дни (Д чч:мм) |
| **Человек** (ФИО) | «Проекция»: «ФИО (по умолчанию - полное написание)», «ФАМИЛИЯ», «ИМЯ», «ОТЧЕСТВО», «И» (инициал имени), «О» (инициал отчества), «ТЕЛЕФОН», «EMAIL» |
| **Список людей** | «Кол-во»: «Все» (через запятую), «Первый», «Все (по строкам)» — каждый с новой строки; плюс «Проекция» — применяется к каждому человеку в списке |
| **Адрес** | галочка «Координаты» — вместо адреса печатаются координаты |
| **Переключатель «да/нет»** | «Переключатель»: «Да / Нет, пустое — прочерк»; «Да / Нет, пустое — „Нет“»; «Квадратик ☑ / ☐»; «да ☑ нет ☐» |

Рядом с названием плашки в листе показывается краткая пометка настройки, например «· DD.MM.YYYY», «· по строкам, фамилия», «· формула» — на печать она не попадает.

Кнопка **«Готово»** закрывает меню.

#### 3.5 Таблицы

**Обычная таблица.** Кнопка «Вставить таблицу» — таблица 2×3 с заголовком. Когда курсор стоит в таблице, над ней появляется меню:

| Кнопка | Действие |
| --- | --- |
| + строка / − строка | добавить строку ниже / удалить строку |
| + столбец / − столбец | добавить столбец справа / удалить столбец |
| ƒ вычисляемая | вставить ячейку с формулой (см. 3.7) |
| заголовок | сделать/снять строку заголовка |
| объединить/разбить | объединить выделенные ячейки или разбить объединённую |
| фон / сброс фона | залить ячейки цветом / убрать заливку |
| границы | включить/выключить рамки таблицы |
| удалить таблицу | удалить всю таблицу |

Ширину столбца меняют перетаскиванием границы мышью; высоту строки — перетаскиванием нижней границы (строка не станет ниже своего содержимого).

**Таблица из списка данных** (например, выполненные работы, контакты, материалы, история стадий). Нажмите в панели переменных пункт «… (таблица…)» — откроется окно «Вставка».

Два режима:

1. **«Таблица»** — на каждую запись из данных будет отдельная строка.
   * Галочками отметьте **какие столбцы показывать**, перетаскиванием (за значок слева) задайте **порядок**.
   * **Заголовок столбца можно переименовать** — впишите своё название в поле.
   * «Строка заголовков» — добавить строку с названиями столбцов.
   * «Строка итогов» — добавить строку «Итого» с суммами по числовым столбцам (опция есть только у таблиц, где есть числовые данные).
   * **«+ Ручная колонка»** — добавляет столбец, который в готовой форме будет пустым (для записи от руки) либо будет считаться по формуле. Тип: «Текст», «Число», «Деньги», «Формула», «Дата», «Да/Нет». Для «Формулы» доступен выбор «Показывать как: Число/Деньги».
   * Кнопка «Вставить» неактивна, пока нет ни одного столбца; для «Формулы» нужно задать выражение.
2. **«Только первое значение»** — вместо таблицы вставляется одна переменная: выбранное поле из **первой** записи (например, ФИО первого контакта).

> Часть столбцов у «Выполненных работ» (техники, материалы) по умолчанию не отмечена — отметьте их галочкой, если нужны.

Если по заявке данных для таблицы нет, таблица покажется с **одной строкой прочерков** (или пустой — в зависимости от настройки «Пустые значения»).

#### 3.6 Особые блоки

#### Блок «Выполнение»

Выводит подробный отчёт по всем выполненным работам: для каждой работы — название, объект, даты начала/окончания, таблицу «Наименование / Кол-во / Стоимость / Сумма» и по желанию:

* **Исполнителей** — строки исполнителей с их ставкой и оплачиваемыми часами;
* **Материалы** — израсходованные материалы;
* **Комментарий** — примечание к работе.

Вставка: в панели «Выполненные работы» → «Выполнение (блок…)» → отметьте нужное → «Вставить». Если работ по заявке нет, вместо блока печатается «Нет выполненных работ».

**Итоги.** В группе «Выполненные работы» есть отдельные значения-суммы, которые можно поставить в любое место документа: «Σ стоимость работ», «Σ стоимость материалов», «Σ стоимость исполнителей» и **«Итого к оплате»**. К ним тоже можно применить формулу (например, добавить НДС).

**Как считаются деньги**:

* стоимость работы — цена вида работ (**не** умножается на длительность);
* исполнитель — ставка × оплачиваемые часы, где часы — длительность работы, **округлённая вверх** до целого часа;
* материал — цена × количество; если у материала нет цены, «Стоимость» и «Сумма» остаются пустыми (а не 0,00).

#### Блок «Чек-листы»

Панель «Чек-листы» → «Чек-листы (вставить…)». Два варианта:

1. **«Блок (все чек-листы)»** — выводит все чек-листы заявки, каждый своей таблицей.
   * «Все чек-листы» или «Только выполненные».
   * Столбцы: «Наименование», «Описание», «Значение», «Отметка» (по умолчанию выключена). Галочка — показывать, перетаскивание — порядок, **заголовок можно переименовать**. «+ Свой столбец» — пустой столбец для записи от руки.
   * «Вид отметки»: `✓ / ✗`, «Да / Нет», `☑ / ☐`, «да ☑ нет ☐».
   * «Описание чек-листа» — печатать пояснение к самому чек-листу перед таблицей пунктов.
2. **«Таблица (один чек-лист)»** — выберите конкретный чек-лист из списка и поля, которые нужны; получится таблица «Поле — Значение». Галка «Колонка отметки ✓» добавляет столбец для отметки **от руки**: в нём печатается `_________`, состояние пункта из заявки туда не попадает.

> Для пунктов с доп полем переключатель ответ показывается в столбце «Отметка», а «Значение» у них остаётся пустым.

#### Картинки из заявки

В панели есть пункты **«Вложения (только изображения)»** у заявки, выполненных работ и чек-листов, а также дополнительные поля типа «Рисунок»/«Вложенный файл». Такой пункт вставляет **рамку**, куда при печати подставятся все подходящие картинки подряд. Размер **одной** картинки меняется перетаскиванием уголка рамки. Файлы, которые не являются картинками, пропускаются.

#### Подпись, план объекта, QR-код

* **Картинка подписи** — подпись клиента, собранная при закрытии заявки. Если подписи нет, остаётся пустое место. Рядом доступны переменные «ФИО подписанта» и «Должность подписанта».
* **План объекта** — схема объекта, где находится оборудование. Если плана нет — рамка «План объекта не задан».
* **QR-код объекта** — QR-код маркировки объекта (по нему можно попасть на паспорт объекта и подать заявку). Если маркировка объекта не настроена в HubEx, в форме будет рамка «QR-код не настроен».

Размер каждой из этих картинок меняется за уголок.

#### Разрыв страницы

Кнопка «Разрыв страницы» на панели инструментов (см. 3.2).

#### 3.7 Вычисляемые значения (формулы)

Формула нужна, чтобы получить число из других чисел: «Количество × Цена», «Сумма + НДС» и т.п. Разрешены **числа, четыре действия (+ − × ÷), скобки и переменные**.

**Формула у числовой переменной.** Кликните по плашке числа → в строке «Считать» нажмите поле «задать выражение…». Откроется панель «Что считать в этой ячейке»:

* выбирайте значения из списка (в формулу можно подставлять только числовые поля);
* вводите числа и знаки с клавиатуры;
* если собственное значение переменной в расчёте не участвует, панель предупредит об этом.

**Вычисляемая ячейка** — ячейка без своего значения, полностью получаемая расчётом. Добавьте её через кнопку «ƒ вычисляемая» в меню таблицы, пункт «ƒ Вычисляемое значение…» в подсказке `{{` или в группе «Документ». Панель выражения откроется сама. Пока выражение не задано, в готовой форме будет прочерк.

Внутри таблицы из списка в формуле доступны **поля текущей строки** (например, «Количество» и «Стоимость» этой строки). Итоговая строка умеет суммировать вычисляемый столбец.

Правила, о которых стоит помнить:

* если хотя бы одного значения в выражении **нет** (данные не заполнены) — результатом будет **прочерк**, а не «0»;
* деление на ноль тоже даёт прочерк;
* панель не пропускает ошибочные выражения и подсказывает, что не так («Между значениями не выбрано действие», «Скобки не сходятся» и т.д.).

#### 3.8 Колонтитулы и номера страниц

Колонтитул — строка вверху или внизу **каждой страницы** (например, «Заявка № … | | Стр. 2 из 5»).

* В нижней/верхней части листа есть пунктирные кнопки **«Верхний колонтитул»** и **«Нижний колонтитул»** — нажмите, чтобы добавить.
* Колонтитул состоит из **трёх зон**: слева, по центру, справа. В каждую можно вписать текст и вставить переменные (только простые — таблицы, картинки и блоки в колонтитуле недоступны; такие пункты в панели переменных в этот момент серые).
* Кнопки **«№ стр.»** и **«всего стр.»** вставляют номер страницы и общее число страниц.
* Крестик рядом с названием убирает колонтитул; внизу появится сообщение с кнопкой **«Вернуть»**.

> **Как это выглядит в готовом документе.** Настоящие номера страниц есть **только в файле Word** (DOCX). На экране, в **PDF и при печати** на месте номера и числа страниц на каждой странице стоит «1» — браузер их не расставляет, поэтому «Стр. 2 из 5» в PDF напечатается как «Стр. 1 из 1». Высота каждого колонтитула — 12 мм. При печати из браузера снимите в окне печати галочку «Колонтитулы», иначе браузер добавит свои дату, адрес и номер страницы (готовая форма сама напомнит об этом).

#### 3.9 Автосохранение в браузере

Пока вы работаете, конструктор **автоматически сохраняет изменения** формы в вашем браузере.

Если вы закрыли окно или истёк доступ, при следующем открытии этой формы вверху появится жёлтая плашка «Найден несохранённый черновик от …» с кнопками:

* **«Восстановить»** — вернуть несохранённые правки (вместе с настройками формы и галками «Редактируемая» и «Мобильная»; у выключенной формы галка «Мобильная» не меняется);
* **«Отклонить»** — удалить копию и оставить сохранённую версию.

Плашка появляется, только если копия новее сохранённой формы. Копию новой, ни разу не сохранённой формы конструктор предложит при следующем нажатии «Создать форму». Автоматически сохраненный черновик хранится только в этом браузере на этом компьютере — на другом устройстве её не будет.

Это **не** замена кнопки «Сохранить»: изменения сораняются финально только по кнопке, а пользователи увидят их только после выбора кнопки — «Опубликовать», «Сохранить» у опубликованной формы или «Включить» у выключенной (см. 3.10).

#### 3.10 Публикация и доступ по ролям

**Опубликовать** — значит сделать форму доступной на заявках. Нажмите **«Опубликовать»**.

Что произойдёт: форма сохранится, зарегистрируется в HubEx, включится, и подписью станет «Опубликована».

У опубликованной (и включённой) формы кнопка одна и называется «Сохранить». **Любое сохранение сразу меняет форму у всех пользователей** — будьте внимательны, правя рабочую форму.

**Выключенная форма** (значок «Выключена») — опубликованная форма, которую выключили переключателем «Активна» в списке. Пользователи её не видят. Кнопок у неё две:

* **«Сохранить»** — сохраняет форму в базе; пользователи изменений не увидят;
* **«Включить»** — сохраняет и заново публикует форму: она снова видна пользователям, переключатель «Активна» в списке включится, появится сообщение «Форма включена».

**Доступ по ролям.** Кнопка «Доступ по ролям» раскрывает список ролей вашей компании с галочками. Форма будет видна только тем ролям, которые отмечены.

![](https://wiki.hubex.ru/attachments/images/FAQ/USER/PrintingFormDesigner/IMAGE8.jpg)

Важно:

* изменения ролей применяются **только основной кнопкой** — «Опубликовать», «Сохранить» у опубликованной формы или «Включить» у выключенной (под списком так и написано: «Применится при публикации»), а не в момент клика по галочке. «Сохранить» у черновика и у выключенной формы роли не меняет;

**Мобильная.** Включив галочку «Мобильная» и опубликовав форму, вы добавляете её в мобильное приложение HubEx (доступ по ролям для приложения — те же роли). Если галочку снять и сохранить, форма из приложения пропадёт. У выключенной формы галка заблокирована с подсказкой «Форма выключена: включите её, чтобы изменить встраивание в мобильное приложение».

**Выключить форму на время** можно в списке переключателем «Активна» (см. раздел 2) — она пропадёт и с заявок, и из мобильного приложения. Вернуть её можно там же или кнопкой «Включить» в конструкторе.

### 4. Работа с готовой формой на заявке

Откройте заявку и запустите форму (в HubEx она подключена как отдельный раздел/вкладка с названием формы). Несколько секунд крутится индикатор — идёт сбор данных заявки, затем появляется документ.

![](https://wiki.hubex.ru/attachments/images/FAQ/USER/PrintingFormDesigner/IMAGE9.jpg)

#### Что на экране

Вверху — панель:

* **название формы** и **«Заявка № …»**;
* **«Редактировать»** — есть только у форм, где включена настройка «Редактируемая»;
* **«Скачать DOCX»** — сохранить документ в Word;
* **«PDF / Печать»** — печать или сохранение в PDF (в мобильном приложении этой кнопки нет);
* метка **«Поправлено вручную»** — появляется, если вы правили документ руками (до перезагрузки страницы).

Ниже — сам документ на листе A4, как он будет напечатан.

![](https://wiki.hubex.ru/attachments/images/FAQ/USER/PrintingFormDesigner/IMAGE10.jpg)

#### Печать и PDF

1. Нажмите **«PDF / Печать»**.
2. Может появиться подсказка: чтобы на бумаге остался только колонтитул вашей формы, в окне печати снимите галочку **«Колонтитулы»**. Нажмите «Печатать» либо «Больше не напоминать».
3. В окне печати браузера выберите принтер или **«Сохранить как PDF»**.

![](https://wiki.hubex.ru/attachments/images/FAQ/USER/PrintingFormDesigner/IMAGE11.jpg)

Печатается ровно то, что видно на листе; панель с кнопками в печать не попадает. Колонтитулы повторяются на каждой странице.

#### Скачивание в Word (DOCX)

Нажмите **«Скачать DOCX»**. Кнопка на время станет «Скачивание…», затем файл появится в загрузках. Файл называется **«Название формы — Номер заявки.docx»**. Документ — обычный файл Word (A4, поля 15 мм) с настоящими колонтитулами и номерами страниц.

> Word — другая программа, поэтому копия **не бывает идентична на 100%** тому, что вы видите на экране (шрифты, отступы, переносы могут немного отличаться). Если критична точная раскладка — используйте PDF.

#### Правка перед печатью

Если форма «Редактируемая»:

1. Нажмите **«Редактировать»** — на листе можно печатать и править текст как в обычном редакторе. Над листом появится оранжевая плашка: *«Режим правки: изменения не сохранятся в заявке — они попадут только в PDF, печать или DOCX»*.
2. Закончив, нажмите **«Готово»**.

Ваши правки **не сохраняются**: если закрыть форму или обновить страницу, документ соберётся заново.

![](https://wiki.hubex.ru/attachments/images/FAQ/USER/PrintingFormDesigner/IMAGE12.jpg)

#### Как выглядят пустые значения

В зависимости от настройки формы, если данных нет, вы увидите либо **прочерк `_________`**, либо пустое место. Ручные столбцы таблиц всегда остаются с прочерком — они для записи от руки.

### 5. Форма в мобильном приложении

Если форма «Мобильная», опубликована и включена, она доступна в мобильном приложении HubEx у тех же ролей.

Отличия от формы в браузере:

* лист автоматически **уменьшается по ширине экрана телефона**;
* кнопки — только значки, без подписей;
* **кнопки печати нет** — в приложении она не работает;
* **«Скачать DOCX»** - во время формирования показывается плашка с шагом («Формируем документ…», «Упаковываем файл…», «Отправляем файл…»).

### 6. Частые вопросы и что делать, если что-то не так

| Ситуация | Что делать |
| --- | --- |
| Форма не появилась на заявке | Убедитесь, что она **опубликована**, переключатель **«Активна»** включён (или нажмите «Включить» в конструкторе), а вашей роли выдан доступ (кнопка «Доступ по ролям», затем основная кнопка — «Опубликовать», «Сохранить» или «Включить»). |
| После публикации пишет «не удалось применить роли: …» | Форма опубликована. Откройте «Доступ по ролям», проверьте галочки и нажмите «Сохранить» ещё раз. |
| «Публикация не удалась … Форма сохранена черновиком» | Нажмите «Опубликовать» ещё раз. Если ошибка повторяется — сообщите администратору. |
| Вместо значения стоит `_________` | Данных в заявке нет (не заполнено поле, нет работ и т.д.) либо не удалось их получить. Форму можно настроить, чтобы пустые значения не показывались («Пустые значения» → «Не отображать»). |
| Плашка переменной красная | Такой переменной больше нет. Удалите её и вставьте нужную заново. |
| Таблица в форме вышла за край листа | Переключите ориентацию на «Альбомная» или уберите лишние столбцы; сужайте столбцы перетаскиванием. |
| Я случайно закрыл конструктор без сохранения | Откройте форму снова (новую — кнопкой «Создать форму») — конструктор предложит «Восстановить» несохранённую копию (только в том же браузере). Правка, сделанная меньше чем за секунду до ухода, в копию могла не попасть. |
| Нужны номера страниц («Стр. 2 из 5») | Скачивайте DOCX: настоящие номера страниц есть только в Word. В PDF и при печати на месте номера печатается «1». |
| Я удалил колонтитул по ошибке | Сразу нажмите «Вернуть» в появившемся внизу сообщении. Позже вернуть нельзя (кнопка «Отменить» на колонтитул не действует). |
| Форма выглядит не так, как я ожидал после Word | Word — другая программа; для точной раскладки используйте PDF. |

### 7. Памятка по значениям и форматам

Так подставляются данные в готовый документ:

| Тип | Как выглядит |
| --- | --- |
| Дата | `05.05.2026`; со временем — `05.05.2026 14:30`; или «5 мая 2026» / «5 мая 2026 14:30» (по настройке). Время показывается **по часовому поясу вашего компьютера** |
| Число | `1 234,5` (пробелы — тысячи, запятая — дробная часть) |
| Деньги | две цифры после запятой: `8 400,00` (если у переменной задано «Знаков» — столько, сколько задано); знак валюты не печатается |
| Список людей | ФИО через запятую (или каждый с новой строки — по настройке) |
