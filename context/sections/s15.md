## Печатные формы

Документы по заявкам: три готовых формы в меню «Печатные формы» (Сервисный акт, Бухгалтерский акт, Счёт на оплату) и «Конструктор печатных форм» для собственных шаблонов, встраиваемых вкладками в заявку.

**Модель.** Готовые формы строятся за период индивидуально по одному Заказчику, могут включать сведения по нескольким Заявкам сразу. Заказчик выбирается из Компаний с типом «Заказчик» или «Наша компания» [s08]. Отбор Заявок: Объект → Стадия → период «С»–«По» (переход на выбранную стадию) → ручной выбор в поле «Заявка». Сервисный акт: работы, трудозатраты исполнителей, израсходованные материалы [s13]. Бухгалтерский акт: унифицированная форма факта продажи услуги, реквизиты по п. 2 ст. 9 ФЗ №402-ФЗ от 06.12.2011 (название и дата документа, реквизиты сторон, перечень услуг/материалов, стоимость, должности и подписи). Счёт на оплату: платёжные реквизиты продавца; формируется исходя из выполненных работ по отфильтрованным Заявкам. Конструктор: шаблон = текст + стандартные таблицы + переменные `{{...}}`; каждый шаблон даёт свою вкладку в заявке с динамической подстановкой.

**Настройка.** Путь: Печатные формы → Сервисный акт / Бухгалтерский акт / Счёт на оплату. Поле «Компания» — наша компания, реквизиты в шапке. «НДС»: «Без НДС», «Без НДС (вычитание НДС)», «НДС сверху», «НДС включен». У Бухгалтерского акта и Счёта: «Тип акта»/«Тип счета» = «Сводный акт»/«Сводный счет» либо «По каждой заявке»; «№ акта»/«№ счета» свободной формы. Кнопка «Просмотр отчета»; печать — «Файл → Печать»; экспорт — «Главная → Экспорт» (pdf, xlsx, docx, xml и др.; для правки рекомендуется docx). Конструктор: Конструктор отчётов → «+» → «Название» (= название вкладки), «Описание» (необязательно) → «Сохранить». Меню трёх точек: «Удалить», «Деактивировать»/«Активировать».

**Ограничения.** При подключении каждой из трёх форм в панели «Параметры» доступно ограниченное количество фильтров; расширение — через help@hubex.ru. В поле «Объект» выбирается только родительский объект (дочерние выбираются автоматически). Конструктор не поддерживает: кастомизируемые таблицы, вычисления в форме, условное отображение блоков — такие формы делает команда HubEx в рамках индивидуальных доработок. Стандартные таблицы конструктора: чек-листы, список выполненных работ.

**⚠ Грабли.** У Бухгалтерского акта и Счёта поле «Стадия» по умолчанию — «Выполнена» (стадия с действием «Завершить работу по заявке»); у Сервисного акта умолчание не указано. «№ акта»/«№ счета» по умолчанию берётся из номера Заявки; заполненное поле выводится перед номером Заявки. При изменении любых настроек «Просмотр отчета» нужно нажимать повторно. Логотип компании отображается в левом верхнем углу Сервисного акта; без загруженного логотипа — стандартный логотип HubEx [s23]. В конструкторе переменная вставляется в конец формы — переместить вручную; дата-время подставляется по часовому поясу тенанта (по умолчанию); отсутствующее значение даёт пустую строку; «Распечатать» вызывает окно печати браузера, PDF — средствами браузера. Деактивированная форма скрыта в заявках, но сохранена.
