## Приглашения, доступ и графики работы

Регистрация новых пользователей по приглашению, ограничение видимости файлов и графики работы (недельные/сменные), используемые при назначении, автоназначении и SLA.

**Модель.** После создания «Сотрудника» или «Заказчика» в web-приложении система шлёт письмо со ссылкой на регистрацию — на указанный e-mail либо sms на телефон; пользователь переходит по ссылке, задаёт пароль, после чего входит в web или мобильное приложение (HubEx Engineer для исполнителя, HubEx Customer для заказчика). Файлы, прикреплённые к «Заявке» или карточке «Объекта», имеют настройку доступа по «Ролям» (роли ведутся в консоли администратора, см. [s09]); настройка в заявке и в объекте не отличается. График работы: два типа — Недельный (рабочее время на каждый из 7 дней) и Сменный (повторяющийся интервал строк типа «Смена»/«Выходной» с количеством дней, напр. 2/2, 1/3, 3/2/3). График назначается сотруднику индивидуально, справочно закрепляется за объектом/оборудованием, и используется как «График обслуживания заявки» в SLA [s12] — пример: график «Понедельник-пятница с 9:00 до 18:00» + плановое время 45 ч, заявка создана в понедельник 9:00 → крайний срок пятница 18:00. Графики применяются в автоназначении по графику, виду работ, навыкам [s12] и в отчёте по отработанному времени и переработкам [s19]. Смены сотрудника редактируются индивидуально (больничный, отпуск, перенос смены).

**Настройка.** Права на файл: контекстное меню (три точки) у файла → «Права доступа» → флажки Ролей; функция доступна только после добавления файла. Флаг «Показать файлы в паспорте объекта» открывает файл при сканировании QR-кода и просмотре паспорта [s07]. Графики: консоль администратора → «Структура предприятия» → «Графики работы» → «Создать график»; поля «Наименование», дни/время чч:мм, флаг «Назначить дату начала календаря», кнопка «Показать график в календаре». График сотрудника: «Пользователи» → «Сотрудники» → карточка → вкладка «Трудоустройство». Правка смены: там же кнопка «Редактировать смену», либо «Заявки» → «Расписание заявок» (режимы день/неделя/месяц) → три точки → «Редактировать смену»; варианты «На смене» / «Не на смене», далее «Сохранить». Исполнитель правит свой график сам в мобильном приложении (боковое меню → иконка исполнителя). Смена в мобильном: «Начать смену» / «Завершить смену». График объекта: «Объекты/оборудование» → карточка → поле «График работы».

**Ограничения.** По умолчанию файлы доступны всем пользователям. Время одной смены не может быть более 24 часов; при большей длительности создают подряд две смены — на 24 часа и на дополнительное время. Предустановленные графики изменять нельзя, свои создавать можно. Графики по умолчанию: «Выходные 9-18», «2/2(4) c 9:00 до 18:00», «2/2(3) с 9:00 до 18:00», «2/2(2) c 9:00 до 18:00», «2/2 c 9:00 до 18:00», «Понедельник-Пятница 9:00-18:00», «Круглосуточный 24/7». Обеденное время в графиках отобразить нельзя. Дата начала не обязательна: без неё график действует со дня создания.

**⚠ Грабли.** Смены можно устанавливать, даже если в карточке сотрудника НЕ выбран график работ. При «Начать смену» другое время начала указать нельзя, «Время по» заполняется автоматически по настройкам графика; чтобы изменить часы, сначала меняют смену, потом жмут «Начать смену». Ночная смена задаётся временем окончания следующего дня (напр. 2:00), длительность с переходом через полночь считается автоматически. После изменений «Показать график в календаре» нужно нажимать повторно. График у объекта — исключительно справочное поле. При постановке заявки на время в форме выбора исполнителя «Начало» = выбранное время, «Окончание» считается по «Плановым трудозатратам» вида работ.
