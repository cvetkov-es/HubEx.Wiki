## QR-коды, паспорт и планы объектов

QR-код — штрихкод, привязанный к данным системы; сканирование с мобильного даёт доступ: ввод новых объектов ([s14]), подача заявок, паспорт объекта, подача заявок незарегистрированными.

**Модель.** QR-код связывает «Объект» и шаблон заявки. Шаблон заявки — образец «Заявки» с полями «Тип заявки», «Объект», «Заказчик», «Вид работ», «Критичность», «Описание заявки», «Исполнитель» (меняются при подаче); нужен также для интеграции с эл. почтой ([s24]). Паспорт объекта — данные «Объекта|Оборудования» в приложениях «HubEx исполнитель»/«HubEx заказчик» при сканировании QR по кнопке подачи заявки. Публичный шаблон → неполный паспорт открывается в мобильном браузере любым сканером QR. «История обслуживания» доступна только в приложении исполнителя. Привязка QR, ранее не использованного в HubEx, автоматически создаёт шаблон — неопубликованный, без «Тип заявки», «Вид работ», «Приглашение» и разрешения на подачу. Пин на плане в карточке «Объекта» — расположение по умолчанию, подставляется в «Заявку». Дочерний объект без своего плана подтягивает план родителя ([s06]); если планы у обоих — выбирается любой.

**Настройка.** Путь: Карточка Объекта → «QR-коды» → «Маркировать». Путь: Заявки → Маркировка → «Создать QR-код»; флажки «Опубликовать», «Разрешить подачу заявки из Web», «Разрешить саморегистрацию» (требует «Разрешить регистрацию без верификациии»), «Обязательная саморегистрация по QR-коду»; «Приглашение» задаёт Роль и Участок нового пользователя, создаётся в Пользователи → Приглашение. Экспорт QR-кодов — архив .zip. Путь: Роль → «Приложения» → «Электронный паспорт оборудования» — включить и для Роли из «Приглашения» ([s09]). Подтверждение пребывания: консоль администрирования → Настройки заявки → Стадии заявки → стадия → «Требование» → «Отсканировать QR код объекта» ([s01]). Путь: Карточка Объекта → «Объект|Оборудование» → «План объекта». Путь: Объекты|Оборудование → Объекты|Оборудование → «Фильтры» (сохраняемые быстрые фильтры), флажки объектов → «Редактировать».

**Ограничения.** Один план на «Объект»; .jpg, .jpeg, .png; загрузка только в web-версии. «Вид работ» шаблона — из установленных в карточке «Объекта». Без привязки QR к «Объекту» паспорт пустой. QR сверяется с QR карточки «Объекта» из «Заявки»; при несовпадении — уведомление о неверном коде, перехода нет. Массово меняются: Родительский объект, Вид работ, Участок, Навык, Чек-лист, Ответственный, Тип/Класс объекта, Компания-владелец, Мобильность, публикация, график работы.

**⚠ Грабли.** Пин, переставленный в «Заявке», НЕ меняет расположение по умолчанию в карточке «Объекта». Заказчику просмотр паспорта не доступен по умолчанию. При «Обязательной саморегистрации» пункт «Не получать уведомления» недоступен. Замена «Типа объекта» групповым редактированием возможна только для дочерних объектов. В массовом редактировании списки «Видов работ» и «Участков» — все значения справочников.
