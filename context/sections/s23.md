## Первые шаги, база знаний и брендирование

Стартовый порядок настройки HubEx, глоссарий терминов, встроенный ИИ-помощник, подключаемая база знаний, брендирование логотипом.

**Модель.** Работа складывается из двух частей: пользовательские приложения (web и мобильные — заполнение справочников, заявки, аналитика) и консоль администрирования (доступ, работа с заявками, интерфейс). Перед созданием заявок заполняются справочники в порядке: обслуживаемые Компании → Объекты/оборудование → Заказчики → Исполнители. Компании — юр- или физлица, выступающие заказчиками и (или) подрядчиками; туда же вносится своя организация, от лица которой ведётся учёт. Два типа пользователей: «Сотрудники» (лицензируемые, web + приложение «HubEx исполнитель», создают и выполняют заявки; диспетчер, руководитель, сервисный специалист) и «Заказчики» (создают заявки в мобильном приложении заказчика, привязаны к компании-заказчику) — подробнее [s10], [s11]. Объект (оборудование) — элемент инфраструктуры, аналог конфигурационной единицы в ITSM, привязан к компании-заказчику; [s05], [s06]. Способы подачи заявки: вручную (web/мобильные), полуавтоматически сканированием QR-кода [s07], импортом Excel. Глоссарий сводит термины, раскрытые у соседей: жизненный цикл, стадия, статус, тип заявки, срок закрытия — [s01], [s02]; вид работ, навыки, автораспределение, чек-листы — [s12]; участок — [s09]. База знаний — дополнительно подключаемый виджет компании-партнёра HiHub с собственной авторизацией; иерархия: пространства → разделы → статьи; свои роли (Администратор / Редактор / Пользователь), не роли HubEx. HubEx AI — встроенный чат-бот в web-интерфейсе, отвечает по материалам HubEx Wiki, хранит историю переписки (её можно очистить).

**Настройка.** Путь: Боковое меню → Компании → «Создать компанию» (перед началом работы там уже есть одна — ваша). Путь: Боковое меню → Объекты|Оборудование → «Создать объект». Путь: Боковое меню → Заявки → «Создать заявку» (обязательны объект, адрес, описание и др.). Мобильные приложения: «HubEx исполнитель», «HubEx заказчик» (Android, iOS). Подключение базы знаний — запрос в help@hubex.ru; после подключения появляется пункт меню «База знаний», виден пользователям с полномочием роли «Доступ к подключаемым плагинам и отчетам». В БЗ: Пространства → «Создать новое рабочее пространство»; раздел — «+Добавить статью (\/) → Добавить раздел»; учётки — Инструменты → Приглашения; роль — Инструменты → Пользователи пространства → Действия → «Установить роль» / «Удалить из пространства». HubEx AI — иконка 🤖 в правом верхнем углу web-интерфейса. Логотип для брендирования отправляется в help@hubex.ru письмом с файлом.

**Ограничения.** Импортом можно загрузить до 1000 заявок за раз. В базе знаний можно зарегистрировать 5 учётных записей, включая созданную администратором при первом входе. Статусы статьи: «Опубликовано» — всем пользователям; «Черновик» — только учётной записи-автору и администраторам; «Архив» — только редакторам и администраторам. Брендирование доступно для web- и мобильного приложения; обязательное условие — подписка «Корпорация». Логотип: для мобильных .png 364×64 px, для web .svg 91×32 px; шрифты в .svg преобразовать в кривые. Логотип компании отображается в web-приложении, в Сервисном акте, в Отчёте для клиента, в Акте выполненных работ.

**⚠ Грабли.** Если детальный учёт по объектам заказчика не нужен, заводится один обслуживаемый объект — он автоматически подставляется в заявку при выборе заказчика. Регистрироваться в БЗ рекомендуется администратору бизнес-аккаунта HubEx: первый зарегистрировавшийся становится создателем и по умолчанию администратором БЗ. При нескольких пространствах учётку сначала привязывают к выбранному пространству; для доступа ко всем — выбрать пространство «Общая база знаний». При первом входе в БЗ доступен демонстрационный раздел, его можно очистить. Несколько сотрудников могут работать в БЗ под одной учётной записью. HubEx AI может допускать неточности в сложных или нестандартных случаях; для критичных вопросов — поддержка. Вертикальный логотип рекомендуется трансформировать в «Название компании + логотип». Страница HubExVids — каталог обучающих видеороликов, фактического содержания по функционалу не несёт.
