## Создание и редактирование объектов

Ввод объектов (оборудования) в систему: шаблоны для массового создания через мобильное приложение, публикация, редактирование карточки, мобильное оборудование, удаление. Типы и классы — [s05], QR-коды и паспорт объекта — [s07].

**Модель.** Шаблон объектов — образец карточки Объекта с заполненными полями «Родительский объект», «Компания-владелец», «Тип объекта», «Участок», «Вид работ», «Ответственный за объект»; по нему исполнитель создаёт объекты в мобильном приложении в меню «Приемка и маркировка». Варианты меню: приемка без QR-кода (по шаблону или без), приемка по QR-коду (пункт «Новое оборудование»), маркировка по QR-коду — привязка не использованного ранее в HubEx QR-кода к существующему объекту (пункт «Существующее оборудование»). При привязке QR-кода к Объекту или создании Объекта по QR-коду автоматически создаётся шаблон заявки в меню «Заявки — Маркировка» [s07]. Мобильное оборудование — оборудование с динамичным адресом: новый адрес указывается в Заявке и сохраняется в карточке Объекта. Мобильным может быть только объект с Типом оборудования, где стоит флажок «Обязательное наличие адреса (при создании объекта оборудования)»; это родительские объекты, дочерние наследуют адрес от родителя. История перемещений — экспортом Заявок с отбором по оборудованию [s19].

**Настройка.** Путь: Объекты|Оборудование → Шаблон объектов и оборудования. Вкладка «Объект|Оборудование»: «Название шаблона» (видно в мобильном приложении), «Описание шаблона» (необязательно), «Родительский элемент», «Тип оборудования», «Название» (если пусто — подставится название шаблона), флажок «Мобильное оборудование», «Участок», «График работы оборудования» (справочный, необязательный), «Класс оборудования» (без учёта — вариант «По умолчанию»). Вкладка «Обслуживание»: «Виды работ», «На гарантии до», «Ответственный за объект». Вкладка «Дополнительные поля» [s16]. Публикация: Путь: Объекты|Оборудование → фильтр неопубликованных → контекстное меню («три точки») → «Опубликовать». Редактирование в мобильном приложении — через паспорт объекта (при подаче заявки по QR-коду, из списка «Объекты|Оборудование», из карточки Объекта в заявке); правится «Класс оборудования», «Описание», «Файлы», доп. поля на вкладке «Характеристики»; сохранение — галочка вверху справа. Полномочие: консоль администрирования → Роли → раздел «Объекты» → «Изменение данных объекта» [s09]. Удаление объекта: карточка или список → «три точки» → «Удалить» / «Удалить с вложенными объектами»; групповое — галочки + «Удалить». Скрыть удалённые: Администрирование → Роли → блоки «Компании», «Объекты», «Пользователи и контакты» → поиск «удаленные» → отключить «Удаленные объекты» и др.

**Ограничения.** Объекты, созданные в мобильном приложении исполнителя, создаются неопубликованными — по ним нельзя создавать заявки. В мобильном приложении без выбора Класса объект создать нельзя. Нельзя изменить «Тип оборудования» и «Контактные лица». Нельзя удалять объекты, участвующие в активных заявках. Удалённый объект нельзя восстановить — только создать новый по примеру старого. Прямое удаление справочников Объекты, Сотрудники, Заказчики, Компании и Заявок не предусмотрено из-за ссылочных связей. При удалении компании все привязанные объекты снимаются с публикации. Удалённые объекты видны по фильтру «Видимость», компании — «Видимость компаний».

**⚠ Грабли.** Неопубликованные объекты отмечены оранжевым маркером. Дочерние объекты наследуют адрес от родителя, поэтому их адрес как мобильных не меняется. Смена адреса во второй заявке не меняет адрес в первой — там правят вручную. Готовые QR-стикеры с логотипом заказываются кнопкой «QR-стикеры на вашем оборудовании» → «Заказать QR-стикеры», запрос уходит в поддержку HubEx.
