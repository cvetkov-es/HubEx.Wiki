## Создание и действия с заявками

Заявка — карточка задачи (содержание, исполнители, сроки), создаётся в разрезе объекта, хранит историю обращений по объекту. Учёт по заявкам даёт фиксацию обращений клиентов, формирование платёжных документов и счетов, планирование загрузки сотрудников. Жизненный цикл и стадии — [s01], атрибуты и приоритизация — [s02].

**Модель.** Заявка ← Тип заявки (определяет стадии и срок закрытия) — единственное обязательное поле формы, отключить нельзя. Заявка → Заказчик (компания), Объект/оборудование, Вид работ (доступны только закреплённые за выбранным объектом), Договор обслуживания, План объекта (из карточки объекта), Компания-плательщик (может отличаться от заказчика), Контактные лица, Наша компания (вручную из компаний вида «Наша компания»), Родительская заявка, Инициатор, Исполнитель (один или несколько). Иерархия: дочерние заявки подчиняются родительским; дочерняя не отличается от обычной, отличие — заполненное поле «Родительская заявка»; любую заявку можно сделать дочерней, заполнив это поле. При создании на форме одна вкладка «Заявка»; после сохранения появляются «Необходимые материалы», «Сообщения», «Чек-листы», «Дочерние заявки», «Выполнение», «Акт выполненных работ», «История изменений». Блоки вкладки «Заявка»: Заявка, Обслуживание заказчика, Трудозатраты, Детальная информация. Плановая заявка — шаблон автосоздания заявок по расписанию; График обслуживания объектов — форма представления плановых заявок. Назначение исполнителя: вручную, перетаскиванием в «Расписание заявок» (только один сотрудник), правилом автоназначения, привязанным к стадии (только один сотрудник) — [s12].

**Настройка.** Путь: Заявки → Все заявки → «Создать заявку». Путь: Заявки → Планировщик работ → «Создать заявку» (переключатель между «Плановые заявки» и «Графиком обслуживания объектов»). Путь (консоль администрирования): Настройки заявки → Поля на форме заявки — видимость и заполнение всех необязательных полей в разрезе «Ролей» и «Стадий заявки»; для поля «Актуальный исполнитель по заявке» значение «RW (чтение и запись)» разрешает выбор исполнителя. Путь: Администрирование → Роли → Полномочия → блок «Заявки» → «Удаление заявок», «Удалять незакрытые заявки» (право удаления рекомендуется давать только начальникам сервисной службы либо администраторам системы). Путь: Администрирование → Роли → раздел «Объекты» → «Объекты на участках пользователя»; раздел «Заявки» → «Заявки, где пользователь — ответственный за объект по заявке», «Заявки на объектах, доступных пользователю» — без них исполнитель не видит заявки в общем списке. Выбор исполнителя: «+Добавить исполнителя», сортировка «По релевантности» (учитывает «Вид работ» заявки, «Ответственный за объект», «Участок», «Навыки», «График работ» из карточки объекта; чем больше совпадений с карточкой сотрудника, тем выше) или «ФИО исполнителя» (А→Я); кнопка «Календарь» справа от имени показывает занятость. Плановая заявка: поля «Название», «Тип заявки» (только один), «Вид работ» (только один; по нему подбираются объекты), «Объект/оборудование» («К списку объектов», «Подобрать объекты»), «Описание», «Исполнитель», «Плановое создание заявок» (Ежедневно, Еженедельно и т.д.), «Отложить начало выполнения работ» (сдвигает срок закрытия), «Ограничить повторения» (период или количество), переключатель «Автоматическое назначение исполнителя»; запуск — «Сохранить и запланировать». Список заявок: карточное отображение (по умолчанию), табличное (настройка столбцов, доп.поля в таблицу), на карте — [s20]; фильтры в правом боковом меню, быстрые фильтры, «Видимость заявок» → «Только удаленные», «Избранные заявки» → «Только избранные заявки». Контекстное меню (три точки) заявки: «Копировать», «Удалить», «Добавить в избранное»/«Убрать из избранного». Перевод стадии: кнопка «Перейти на стадию» → «Сохранить».

**Ограничения.** Номер заявки — максимум 32 символа, присваивается автоматически по шаблону из консоли администрирования, может быть изменён вручную. Импорт — до 2000 заявок за раз. Массовое редактирование заявок — на данный момент только исполнитель/исполнители; групповое назначение доступно для карточного и табличного представления, вариант «Нет исполнителя» снимает назначение. Копирование доступно только в карточном представлении. Оценочные и фактические трудозатраты — в часах; оценочная и фактическая стоимость — числом; «Неисправность обнаружена» — дата. «Метод подачи заявки» заполняется автоматически. Крайний срок закрытия рассчитывается правилом SLA [s12]; если ни одного правила SLA не создано или не включено, срок считается по сроку закрытия «Типа заявки». Просроченной считается заявка, выполненная или закрытая позже крайнего срока; по умолчанию выполнение происходит на стадиях «Выполнена» и «Закрыта». Для роли сервисного специалиста могут быть введены ограничения на установление часовой ставки и оценки стоимости работы. Для графика обслуживания обязателен выбор «Типа заявки», «Заказчик» — одно из условий формирования; в списке заказчиков только те, по которым созданы плановые заявки; выбрать можно только родительский объект (дочерние подтягиваются автоматически); группировка периода — по дням/неделям/месяцам; экспорт в pdf, xlsx, docx, xml и другие, для редактирования рекомендуется xlsx.

**⚠ Грабли.** После создания заявки её тип изменить невозможно — заявку копируют, в копии меняют тип, некорректную удаляют; при копировании поле «Номер заявки» остаётся пустым и заполняется при сохранении. Заявки не удаляются полностью, а скрываются из списка; просмотр удалённых доступен только учётной записи владельца тенанта. В web заявку можно подать без заказчика, объекта, адреса и вида работ (внутренние задачи), но в мобильном приложении при создании поля «Заказчик», «Объект», «Вид работ», «Адрес» обязательны; заявка из web с пустыми полями в мобильном просматривается и редактируется обычно. Если в карточке объекта установлен флажок «Мобильное оборудование», изменение адреса в заявке меняет адрес и в карточке объекта. В краткой форме создания дочерней заявки нельзя выбрать объект — он наследуется от родительской; сменить можно после сохранения. Если дочерние заявки не отображаются на вкладке при ненулевом счётчике — кнопка «Настройки» (шестерёнка), выбрать поля или «Выбрать все». Изменения стадии действуют для всех типов заявок, в чей жизненный цикл включена эта стадия. Для редактирования плановой заявки её сначала нужно «Приостановить», затем снова «Сохранить и запланировать». График строится только после нажатия «Просмотр отчета», повторно при любом изменении настроек. При нескольких исполнителях время выполнения общее: 2 часа для двоих отразятся в акте как 2 часа каждому; по умолчанию в выполненную работу добавляются все назначенные исполнители. Заблокированное поле «Исполнитель» (значок замка) — вопрос доступа к полям формы, он настраивается отдельно от ролей. Создание дочерних заявок доступно только в web-приложении. Альтернативные каналы подачи (QR, импорт) — [s04], [s07].
